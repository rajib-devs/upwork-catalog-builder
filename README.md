# upwork-catalog-builder

A Claude skill that turns one prompt into a complete, paste-ready Upwork Project Catalog listing, following the order of Upwork's create-project form, with every character limit checked.

## Contents
- `SKILL.md`: workflow and quality rules
- `references/upwork-form-rules.md`: field limits and lessons learned
- `references/proof-bank.md`: verified proof points, positioning, writing rules
- `references/example-malware-offer.md`: finished malware removal offer used as the template
- `scripts/check_limits.py`: checks field lengths and em dashes before publishing

## Usage
Install the skill in Claude, then prompt: "Create my next catalog project for WordPress migration."

## Updating
When your rate, proof, or live offers change, edit `references/proof-bank.md`.
