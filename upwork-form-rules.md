# Upwork Project Catalog form rules and lessons

Limits observed directly in Upwork's create-project form (Sep 2026). Re-check if Upwork changes the form.

## Overview
- Title: starts with "You will get". Keep it specific to the outcome.
- Website Specialization and Supported Plugin Types: selecting all is fine when the service genuinely applies to any site type (malware removal, migration, maintenance). They work as search filters.
- WordPress Plugins (optional): only tick plugins the user has hands-on experience with. Exclude non-WordPress items (OpenCart is a separate platform) and irrelevant ones (ClickBank, AdSense). A focused list looks more credible than every box ticked.
- Search tags: maximum 5. Prefer Upwork's suggested tags because they match real searches. Custom tags are allowed (type, then press Enter). Avoid over-broad tags like "wordpress" that thousands of listings use.

## Pricing
- Custom tier title: max 30 characters.
- Custom tier description: max 80 characters. This is the limit that gets exceeded most often, so always count.
- Delivery days per tier.
- Revisions: avoid 0, it makes buyers hesitate. Default 1, 1, 2.

## Service tier options
Tick per tier to match what each tier actually includes. Higher tiers include everything below them.

## Add-ons
- Fast Delivery: set faster days and a real extra price per tier.
- Additional Revision: real price.
- Untick any option that is already a tier differentiator.
- Custom add-on: title, description, price, additional days. Good pattern: "Additional website" for multi-site jobs.

## Gallery
- Images: up to 20, jpg or png, up to 10 MB each, under 4,000 px wide or tall.
- Video: one mp4, up to 100 MB, under 90 seconds (under 60 recommended). Do not reuse a general profile intro video if it shows Upwork logos or badges or is not about this project.
- Sample documents: up to 2 PDFs, under 2 MB each. Clients only see the first 3 pages, so put the strongest content first.
- Guidelines to avoid: blurry or badly cropped images, text-heavy images, Upwork logos or badges, references to other companies or services, unrelated work. Breaking these can get the project rejected.
- Before uploading any PDF, check its file properties for hidden metadata (author email, original filename, folder paths containing client names).

## Requirements
- Each requirement: min 10, max 250 characters. Answer type can be Free Text; clients can attach files.
- Mark the main requirement as mandatory.
- Add a separate short mandatory question for the website URL.
- Include a line offering guidance for unsure buyers, and suggest a separate removable login for security.

## Description
- Project summary: min 120, max 1,200 characters.
- Project steps: Upwork shows 3 default steps (purchase, complete, approve). Add the user's own process steps with "Add a step". Keep each step title short with a one-line explanation.
- FAQs: up to 5. Answer max 250 characters. Do not type numbers in the question text; Upwork formats the list itself.

## Finalize
- Maximum simultaneous projects: for urgent services with 1 to 3 day delivery, start at 2. A late delivery hurts JSS more than a missed sale. Raise it once real order flow is known.
- Terms and privacy checkboxes are the user's own agreement; leave them for the user.
- Upwork reviews every catalog project before it goes live, usually within a few days.
